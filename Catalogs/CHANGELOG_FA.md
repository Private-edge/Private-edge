# 📋 تغییرات نسخهٔ v1.1.15

**تاریخ:** ۲۰۲۶-۰۸-۲۹ · پایه: v1.1.14 (کد یکسان با v1.1.13)

## ✅ فیکس‌ها

### ۱. Echo شدن subprotocol حتی بدون early data معتبر (مهم — سازگاری کلاینت‌ها)

**قبلاً:** اگر کلاینت هدر `Sec-WebSocket-Protocol` می‌فرستاد ولی `decodeEarlyData` مقدار نامعتبر برمی‌گرداند (base64 خراب، بزرگ‌تر از ۸۱۹۲، یا خالی)، سرور هدر را در پاسخ 101 برنمی‌گرداند.

**مشکل:** طبق RFC 6455، کلاینتی که subprotocol درخواست کرده و پاسخ نمی‌گیرد **باید** اتصال را ببندد → حلقهٔ قطع اتصال در برخی نسخه‌های v2rayNG / Xray.

**حالا:** هدر همیشه وقتی کلاینت فرستاده echo می‌شود — مستقل از محتوای early data.

**تست‌های جدید:** ۳ تست رگرسیون (subprotocol خراب / بزرگ / اسمی مثل `binary`).

### ۲. حذف قدیمی‌ترین ورودی به‌جای پاک‌کردن کل uuidCache

**قبلاً:** با بیش از ۳۲ UUID، `uuidCache.clear()` کل کش را خالی می‌کرد.
**حالا:** فقط قدیمی‌ترین ورودی حذف می‌شود (LRU ساده). در عمل تأثیر کمی داشت (معمولاً ۱ UUID)، ولی رفتار درست‌تر است.

### ۳. هماهنگی نسخه‌ها

`package.json` از `1.1.12` و badge های README از نسخه‌های مختلف به **1.1.15** هماهنگ شدند. بیلدهای `deploy/` بازسازی شدند و `worker.js` / `_worker.js` در ریشه به‌روز شدند.
