## ✅ 修复内容

### 1. 即使 early data 无效也回显 WebSocket 子协议（重要 — 客户端兼容性）

**修复前：** 如果客户端发送了 `Sec-WebSocket-Protocol` 头，但 `decodeEarlyData` 返回无效值（损坏的 base64、超过 8192 字节或为空），服务器不会在 101 响应中返回该头。

**问题：** 根据 RFC 6455，请求了子协议却未收到回显的客户端**必须**关闭连接 → 在部分 v2rayNG / Xray 版本上造成断线重连循环。

**修复后：** 只要客户端发送了该头，服务器就**始终回显** — 与 early data 的内容无关。

**新增测试：** 3 项回归测试（损坏 / 超长 / 命名式子协议如 `binary`）。

### 2. uuidCache 改为淘汰最旧条目，而非清空整个缓存

**修复前：** 超过 32 个 UUID 时，`uuidCache.clear()` 会清空整个缓存。
**修复后：** 仅删除最旧的条目（简单 LRU）。实际影响很小（通常只有 1 个 UUID），但行为更加正确。

### 3. 版本号统一

`package.json` 从 `1.1.12`、README 徽章从各自不同的版本统一为 **1.1.15**。重新构建了 `deploy/` 产物，并更新了根目录的 `worker.js` / `_worker.js`。
